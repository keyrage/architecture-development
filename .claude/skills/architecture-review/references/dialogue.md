# Dialogue contract

Present strengths and the global top ten after synthesis. The user chooses which recommendation to explore; do not force ranking order. Follow-up may target only a selected specialist and must remain tied to the epoch's model ID and published revision.

Record a concise explicit rationale and one disposition: `accepted`, `rejected`, `deferred`, `needs-investigation`, or `undecided`. Undiscussed recommendations remain undecided. Stop preserves all resources. Resume first re-discovers the published revision: unchanged resumes dialogue; movement creates a fresh epoch and requires collection, selected assessments, and synthesis again. A different specialist subset likewise requires a stopped fresh epoch and never rewrites history.
